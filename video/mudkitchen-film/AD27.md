# MudKitchen: "Built for schools like ours" (27s ad)

27.0s at 30fps (810 frames). Remotion compositions live in the `Ad27` folder of
the studio. `src/ad27/timeline.ts` holds the scene ranges, footage trims, crop
focus keys and product hit frames; `src/ad27/captions.ts` holds the script,
VO clip starts and caption timings.

```bash
npm run render:ad27        # sync assets + render all four
npm run studio             # preview / scrub
node scripts/render-stills.mjs ad27-9x16   # QC stills -> out/stills/ad27-9x16/
```

Footage is only the three existing clips in `public/videos/` (1366x768 source,
Lanczos-upscaled proxies in `public/footage/`, rebuilt by `sync-assets` when the
source changes). Product UI is the real MudKitchen demo: the admin window from
film 1 (`AdminWindow`), the parent billing screen (`BillingScreen`) and a port
of the site's newsletter editor (`NewsletterEditorDemoCanvas`) fed by the site's
own demo fixtures.

## VO and caption timing

Delivered take: `audio-source/ad27-vo.mp3` (ElevenLabs "Hope - upbeat and
clear", 24.45s). `npm run split-vo:ad27` cuts it into `public/audio/ad27/vo/01-08.wav`.
The take pauses inside 06 and 07, so the splitter groups 12 spoken segments as
`[1, 1, 1, 1, 1, 2, 2, 3]`, caps inner pauses (06: 0.25s, 07: 0.35s, 08: 0.2s)
and speeds 08 up 1.08x (pitch preserved) so the full CTA fits before 27s.

Captions match the script word for word (checked against `SCRIPT` in
`captions.ts`) and are timed to the split clips; clip 08's three captions break
on its measured sentence pauses.

## Replacing the VO

1. Record one take (ElevenLabs v3, voice "Hope") with a pause between clips.
   Read clip 08 as "MudKitchen. Built for schools like ours. Get started at try mud kitchen dot com."
2. Save as `audio-source/ad27-vo.mp3`.
3. `npm run split-vo:ad27`. If it reports a different segment count, adjust
   `segments` in the ad27 branch of `scripts/split-vo.mjs` to match the take's pauses.
4. `node scripts/sync-assets.mjs` regenerates the audio manifest and prints each
   clip's length against its budget.
5. If a clip runs long, move its `from` in `captions.ts` (and the matching cue)
   or add a `tempo` entry for it, then re-render.

audio stream only). Ducked automatically from 0.45 to 0.22 under each VO clip.

- Full from ~2s; dips at 8.5-11s and 18.6-19.1s; lifts at 11.6s and 19.6s

Final mix: about -23 LUFS integrated, -8 dBFS peak, in line with film 1 (-22 LUFS).
Social platforms normalize playback; for a hotter delivery, run a loudnorm pass on
the rendered mp4s.

live-action shots.

## Known limits

- The source clips are 1366x768, so the 9:16 crops (about 32% of the frame width)
  are upscaled roughly 4x and are softer than the product UI.
- The three clips feature three different women. Per the casting decision, the
  hook teacher, the founder and the payoff teacher are not presented as one person.
